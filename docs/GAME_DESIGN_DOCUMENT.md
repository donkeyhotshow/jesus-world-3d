## 1. КОНЦЕПЦИЯ И ВИДЕНИЕ

**Жанр:** 3D экшн-шутер, выживание в волнах (wave-survival arena)
**Движок:** Three.js r169+, React 19, TypeScript, Vite 7
**POV:** Третье лицо с камерой сзади-сверху
**Платформа:** Браузер (WebGL 2.0)

### Общее видение
Игрок управляет Иисусом Христом, сражающимся с волнами демонов на священной арене. Библейские способности формируют уникальный геймплей: молния, рыба, вино, потоп, парирование, хлеб, благодать, полёт на распятии.

## 3. ФИЗИКА ИГРОКА

### Движение
- Скорость на земле: **5.8 ед/с** (x1.6 при буффе хлеба)
- Скорость в воздухе: **80% от наземной** (воздушный контроль)
- Скорость в полёте (Shift): **9.5 ед/с**
- В воде (Потоп): x1.3 (враги замедлены сильнее)

### Прыжок и гравитация
- Начальная скорость прыжка: **9.5 ед/с**
- Гравитация: **26 ед/с²**
- Coyote time: **0.18с** (прыжок после схода с края)
- Squash на приземлении: 0.22 * |падения|

### Полёт
- Высота: **6.0 ед** над землёй
- Интерполяция: 8% за кадр
- Расход маны: 1.0/с
- Регенерация маны: 0.35/с (движение) → 0.55/с (покой)
- Макс. мана: 5.0

### Физическая модель (псевдокод)
```
if flying:
    y += (FLY_HEIGHT - y) * 0.08
    mana -= 1.0 * dt
else:
    velY -= 26 * dt          // гравитация
    if airborne:
        spd *= 0.8           // воздушный контроль
    y += velY * dt
    if y <= 0: y=0, velY=0
```

## 5. СПОСОБНОСТИ — ДЕТАЛЬНОЕ ОПИСАНИЕ

### ⚡ СМАЙТ (ЛКМ) — Небесная молния
**КД:** 0.35с | **Урон:** 2 (крит x3) | **Скорость:** 18 ед/с | **Крит:** 20%

**Механики:**
- Прямой снаряд, spin-анимация
- При попадании: **knockback** (5.5 ед, крит: 8.5 ед)
- **Цепная молния**: +2 врага в 8 ед. (60% урона)
- Крит: тройной урон + золотые искры + библейская цитата

**Визуал:** Золотой шар + белый крест + кольцо + PointLight(ffdd00, 3.0, 8)
**Следы:** Золотые искры каждые 0.05с в полёте

---

### 🐟 РЫБА (ПКМ) — Святая рыба
**КД:** 0.5с | **Урон:** 1 (крит x3) | **Скорость:** 13 ед/с

**Механики:**
- **Самонаведение**: lerp к ближнему врагу в 20 ед. (dt*4)
- При попадании: **замедляет 3с** (0.4x скорость)
- Текст "🐟 ЗАМЕДЛЕН"

**Визуал:** Синяя рыба с плавниками + глаз + PointLight(44aaff, 1.0, 3)
**Следы:** Голубые пузырьки каждые 0.07с

---

### 🍷 ВИНО (Q) — Священное вино
**КД:** 5с | **Скорость:** 9 ед/с

**Механики:**
- Прямое попадание: **опьяняет 5с** (случайное блуждание)
- Опьяненный при гибели: **взрыв** (+3 урона, радиус 4)
- **AoE splash**: 55% шанс опьянить в радиусе 5
- **Лужа**: красный круг на земле 5с (медленно)

**Визуал:** Фиолетовая бутылка + пурпурный взрыв + красная лужа на земле

---

### ✋ ПАРИРОВАНИЕ (E) — Обращение
**КД:** 7с | **Окно:** 0.8с | **Радиус:** 10 ед.

**Механики:**
- Окно 0.8с: если враг атакует → **контрудар** (-4 ур., 6 ед.)
- **Обращение**: 30% → союзник 18с
- **Ярость**: 70% → 2x скорость 3с
- Белый взрыв при активации

### Состояния врагов
1. **Нормальное**: движется к игроку
2. **Опьянён** (drunk > 0): случайное движение 0.4x
3. **Ярость** (wrath > 0): 2x скорость к игроку
4. **Союзник** (ally): атакует ближайшего врага
5. **Замедлен** (slowed > 0): 0.4x скорость
6. **Knockback**: отлетает от удара

## 9. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### Рендеринг
```
Тени:        PCFSoftShadowMap, 512x512
Тоунмаппинг: ACESFilmicToneMapping, 1.05
Туман:       FogExp2(0x8fbbe0, 0.011)
Физика:      Fixed 1/60s step, max 3 steps/frame
```

### Освещение сцены
- `AmbientLight(0xb0c8e8, 0.7)` — мягкий голубой
- `DirectionalLight(0xfff8e0, 1.6)` — солнце, тени 512
- `HemisphereLight(0x88bbff, 0x227722, 0.4)` — небо/земля
- 8x факелы на столбах арены (PointLight, flickering)
- Jesus halo + crossLight при полёте

### Системы
- Enemies: массив с per-entity физикой
- Projectiles: массив с homing опцией
- Particles: pool, max ~200
- Pickups: массив с hover-анимацией
- Rings: CelestialRing массив (mana pickups)
- FloatTexts: sprites с fade-out
- DeathRings: expanding ring meshes (новая)
- WinePuddles: ground stain meshes (новая)
